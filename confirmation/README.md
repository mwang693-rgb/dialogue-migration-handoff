## Local checks

```bash
python confirmation/make_fake_data.py \
  --out runs/interface-smoke \
  --sources 16 \
  --hidden-size 3584
python confirmation/score.py --validate-old
python -m unittest discover -s tests -v
```

The mock files contain synthetic vectors, not model activations. See [the export format](../docs/activation-interface.md) for loading them and filtering the ordinary-request probe pairs.
