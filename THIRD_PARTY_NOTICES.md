# Sources and redistribution

- **MT-Eval:** https://github.com/KwanWaiChung/MT-Eval . Selected public user prompts/rules are used in the strategy/style histories. The original checker and its MIT license are retained in `third_party/mt_eval/`. The local source checker hash and the license lookup are recorded in `SOURCE.json`. No complete upstream benchmark is mirrored; no official aggregate MT-Eval score is claimed. Reference assistant replies were not supplied as the main target-model history.
- **Qwen2.5-7B-Instruct:** https://huggingface.co/Qwen/Qwen2.5-7B-Instruct . Generated responses are frozen experimental records, not factual endorsements. Model weights/tokenizer files are not redistributed. New inference requires obtaining the model independently and following its applicable terms.
- **Synthetic editing cases:** Task specifications and histories generated for this project. Book/code/table examples are controlled experiments. Model-produced code is parsed, not executed for correctness evaluation.
- **Historical reference code:** The files in `reference_code/` are unchanged snapshots of this project's selected experiment programs and their local imports. Paths and unused imports may refer to the original workspace. They contain no uploaded login credentials. They are preserved for code review/provenance, not represented as fully environment-independent scripts.
- Other datasets named in the overview log (WildChat, CoQA, ConvFinQA, SQA, Multi-IF, MultiTurnInstruct, LongMemEval, MathDial, Lost/GSM8K) are not republished by this handoff. Names identify previously explored routes; consult their original distribution terms before constructing another dataset.

The repository MIT license covers original repository code and documentation; third-party material retains its own notice. The selection was made for course communication after the experiments, not as an unbiased sample of tasks. No private user chat, SSH configuration, token, password, model weights or KV cache dump is intentionally included.
