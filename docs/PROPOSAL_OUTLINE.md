# 课程proposal的简明框架

**暂定题目：** 相同对话历史在角色重放与整体粘贴下的回应规则连续性

**团队：** Moyang Wang；其他成员待补。

## 问题与动机

用户将聊天记录复制到新对话时，历史正文可以相同，但消息角色结构发生变化。我们希望测量：历史中实际执行过的回应规则，能否在后续新问题中延续？目标不是要求所有文字完全相同，也不预设整体粘贴一定降低任务质量。

## 数据处理和对照

借用公开MT-Eval的用户问题和全局回应规则，让Qwen2.5-7B-Instruct逐轮生成历史回复。冻结相同历史正文，从同一检查点独立运行：A真实在线缓存、B按user/assistant重放、C单user粘贴。B/C比较格式，A/B检查重新计算路线。保留历史不合规和最终两组共同失败的案例，分别标记；不按B对C错筛选测试集。

## 待团队确定的两个选择

1. **主要任务：** 优先考虑双版本回答或一种可自动检查的回应规则。现有双版本例子清楚，但扩展没有稳定新增缺口，不能写成已确定的强现象。
2. **主要指标：** 规则合规率；同时检查额外长度要求和生成完整性。文本exact和共同前缀KL作为辅助。局部编辑可作为另一条简单备选，用完整修改和未修改内容保留分开评分。

## 已有探索依据

- 编辑24题：B15、C17、固定提示19、单历史差向量11题完整正确，提醒我们原生不是质量金标准。
- 双版本首批4请求：A/B4、C3；同源扩展10请求B/C均9，不能宣称稳定大规模损失。
- 具体风格表达旧6/6同向，新4历史只2/4，尚不适合作唯一主要终点。

## 后续活动（尚未执行）

先确定一个任务和主要指标，固定新的小批次与生成上限，完成三组基线。存在可重复差异后，再比较简单规则提示与一种有界激活干预，并加入随机/反向及合法规则覆盖对照。若没有差异，仍报告零差异，不通过筛掉共同失败或改指标制造恢复效果。

## 阅读入口

MT-Eval提供公开多轮材料与部分checker；StyleDistance提供风格表示但不是完整聊天风格真值；CAA和In-context Vectors提供干预基线思路。这里仅为阅读导航，不是满足课程“至少四篇文献综述”的完整成稿。论文引用、课程格式与最终分工由团队确认后补齐。
