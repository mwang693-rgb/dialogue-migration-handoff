# 探索实验交接日志

整理：2026-11-04。这是对2026-10-10—14实验的合并同类项记录，不按每个脚本罗列。结果来自已保存记录，没有为本次交接新增模型调用。下面“保留”表示代码/结果已放本仓库；“仅概览”表示只总结该路线，不上传完整旧工程。

## 1. 已经确定的流程

公开数据的问题或自造任务 → Qwen逐轮生成assistant历史 → 检查并冻结 → 相同历史下独立比较输入结构 → 先判断测量是否成立，再谈干预。

A为真实在线缓存，B为原生角色重放，C为单user粘贴。B/C比较格式，A/B检查重算路线。原始数据集的参考回答保留作评分或来源材料，不冒充Qwen在线历史。只做过B/C的旧批次按原样报告。

还没有确定的是：哪个数据任务能产生清楚、稳定的差异，以及哪个指标适合作为课程项目的主要终点。因此此前很多运行是在排除指标误报、历史错误、截断或任务过难，不是正式方法排名。

## 3. 本仓库只交接的三个小实验

### E1：指定编辑与非目标保留（2026-10-10）

- **目的：** 建立容易看懂的任务正确性标准，同时对照全文一致与KL。
- **材料：** 12个自造设计，Qwen实际生成/更新书页、函数、表格；24最终编辑请求，按实际冻结成果构造预期值。
- **选择：** 原批9方法中保留B/C、固定提示、单历史差、随机、反向六列，每列24题完整保留；不是保留成功题。
- **结果：** 完整正确15/17/19/11/15/18（依次B/C/提示/差/随机/反向）；C有时比B好。
- **测量：** 书页/表格JSON结构比较，保留页面/整行成员计数；代码AST，docstring只规范纯缩进。不执行生成函数，不称算法功能验证。
- **KL补充：** 旧开发诊断固定书/代码/表格各1历史、2请求、2参考路径、5条件＝60记录。逐位置重算显示旧稀疏点会漏分叉。
- **限制：** 此批没有真实在线A；旧N就是B。没有盲测，单层参数固定但历史已探索。KL只作分布差异指标，不和正确率互换。

### E2：公开问题中的回应规则（2026-10-14）

- **目的：** 比较已经在历史实际使用的回答方式能否继续。
- **材料：** MT-Eval四类规则各2份源，原始确认＋前三个问题由Qwen回答，问题4/5分别独立续接。8份历史、80最终输出全保留，7份历史在类别checker上连续合规。
- **条件：** A/B/C、B分段、C明确规则提示；当前普通问题不重复旧规则，提示条件只重述规则，不插答案。
- **结果：** 双版本A/B4/4、C3/4；JSON和列表无缺口；固定结尾出现A3/4而B/C4/4，不支持粘贴必然更差。
- **扩展：** 看到单点后，将两份双版本历史的原剩余问题6—10全部继续测试。B/C各9/10，提示10/10，没有新增格式独有缺口。只复用2历史，没有A组。
- **失败记录：** 扩展v1一次生成后计分导入错误、未保存回答；保留在旧工程，本包公开完成的v2共40条。没有把缺失回答算正确。
- **限制：** 双版本checker重在分隔形式，主表不是完整事实质量或200词联合分数；具体疫苗案例另外核过长度。后续扩展已探索，不能称独立盲测。

### E3：具体表达能否复现（2026-10-14）

- **目的：** 将泛泛风格缩为可计数的30种缩略语，确认旧现象是否跨问题成立。
- **材料：** MT-Eval问题流＋首轮口语要求；Qwen回答前三题形成历史，后两题独立续聊。旧6份口语历史48回答，新4历史52回答全部保留。
- **条件：** 旧B/C×保留/删除首轮子句；新批再加在线A和明确正式覆盖请求。删除子句不重写assistant历史，因此是当前输入消融，不是无风格要求下重新生成历史。
- **结果：** 旧B/C实际缩略语9/20，6/6历史C密度更高；新A/B/C为6/7/6，只有2/4历史C密度更高。正式覆盖A/B/C均4/4无已列缩略语。
- **决策：** 新批未达预设工作门槛，不启动steering；不能称干预失败。旧6/6是事后发现，新批为提前冻结确认，二者地位不同。
- **限制：** 特征稀疏、篇幅/题型影响明显；不等于完整私人风格或人格。新题文本只对所记录60个历史文件去重，不证明全新领域。

## 4. 队友接手顺序

1. 读结果报告三张表，先理解B/C和A/B的区别。
2. 在CPU上运行`python scripts/rebuild_report.py`，核对表格确实来自原始回答。
3. 课程proposal建议以E2的回应规则作为候选主线；E1提供评分设计参考，E3解释为什么暂不把风格余弦当主要终点。
4. 下一步先由团队选一种规则、一组数据和一个主要指标，再冻结新的小批次。没有必要接着扫描旧向量或为维持GPU运行而重跑。

本仓库没有重新做实验，也没有把旧结果改成正式论文证据。原工程完整保留；账号、服务器、真实对话和巨量中间张量不属于交接包。
